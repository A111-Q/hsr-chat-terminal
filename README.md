# 星穹铁道 · 角色聊天终端

基于《崩坏：星穹铁道》角色的 AI 聊天网页终端，支持 **49 位角色**（含 4 位 Fate 联动）。单文件前端，无需安装任何依赖，直接打开即用。

## 快速开始

1. **双击打开 `preview.html`**（推荐 Chrome / Edge 等现代浏览器）
2. **接入大模型**：点右上角 **API** → 选服务商（DeepSeek 等）填 Key，测试通过后注入即可
3. 使用前**必须配置 API 大模型**，未配置时发送消息会提示前往配置

> 注意：请勿在 IDE 内嵌预览中直接打开，部分环境会拦截网络请求导致 API 不生效；用浏览器直接打开文件即可。

## 功能特性

- **49 位角色**：8 位深度人设 + 41 位基础人设 + 4 位 Fate 联动（Archer / Saber / 吉尔伽美什 / 远坂凛）
- **第一人称沉浸对话**：以「开拓者」身份与角色交流
- **RAG 知识库**：每角色 13 字段人设 + 2273 条官方真实台词样本，口吻贴近原作
- **多模型支持**：DeepSeek / 豆包 / 通义千问 / 智谱 / Kimi / 硅基流动 / OpenAI
- **历史对话**：DeepSeek 式侧边栏多会话管理（新建 / 切换 / 重命名 / 删除）
- **音乐播放器**：内置 HOYO-MiX「InsIDE」专辑 4 首单曲（单曲循环 / 音量 / 进度拖拽 / 自动播放）
- **未读气泡**：左侧角色列表 QQ 式未读消息提示
- **消息操作**：复制 / 删除 / 重发 / 重新生成
- **消息提示音**：QQ 风格"叮咚"提示音，设置中可开关、可试听，多条消息不叠加

## API 配置

1. 点击右上角 **API** 按钮
2. 选择服务商（DeepSeek / 豆包 / 通义千问 / 智谱 / Kimi / 硅基流动 / OpenAI）
3. 填入 API Key 并选择模型
4. 点击「测试连接」验证后保存

> **重要**：OpenAI 等境外服务需要科学上网环境；国内服务（DeepSeek 等）可直接使用。

## 常见问题

- **角色不回复？** 检查 API Key 是否有效、服务商是否选对；确认已在右上角 API 面板完成「测试连接」并「注入并启用」。
- **音乐不自动播放？** 浏览器自动播放策略会拦截无操作播放，点击播放器的播放键即可（用户手势触发合法）。
