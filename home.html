关于本项目

基于《崩坏：星穹铁道》角色的 AI 聊天网页终端，支持 49 位角色（含 4 位 Fate 联动）。单文件前端，无需安装任何依赖，直接打开即用。

快速开始

  • 双击打开 preview.html（推荐 Chrome / Edge 等现代浏览器）
  • 点右上角 API → 选服务商（DeepSeek 等）填 Key，测试通过后注入即可
  • 使用前必须配置 API 大模型，未配置时发送消息会提示前往配置

功能特性

  • 49 位角色：8 位深度人设 + 41 位基础人设 + 4 位 Fate 联动
  • 第一人称沉浸对话：以「开拓者」身份与角色交流
  • RAG 知识库：每角色 13 字段人设 + 2273 条官方真实台词样本
  • 多模型支持：DeepSeek / 豆包 / 通义千问 / 智谱 / Kimi / 硅基流动 / OpenAI
  • 音乐播放器：内置 HOYO-MiX「InsIDE」专辑 4 首单曲
  • 消息操作：复制 / 删除 / 重发 / 重新生成 / 提示音
