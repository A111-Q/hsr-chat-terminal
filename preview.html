帮助中心

① 快速开始

打开页面即可直接聊天：左侧点击角色头像切换，右侧输入框打字发送。

使用前请先配置 API 大模型：点右上角「API」选择服务商并填写 Key（详见下方「③ API 配置」），配置完成后即可正常对话。

② 对话与角色

发起对话：在底部输入框打字，回车或点发送。

切换角色：左侧列表点击任意角色；每个角色有独立的历史对话。

历史对话：侧边栏「＋ 新对话」开启新会话；悬停会话条目可重命名或删除。

③ API 配置

点右上角「API」打开配置面板。

选择服务商（DeepSeek / 豆包 / 通义千问 / 智谱 / Kimi / 硅基流动 / OpenAI 等），粘贴 API Key，选择模型。

点「测试连接」验证通过后即可正常调用；Key 仅本次会话有效，关闭页面后自动清除，不会保存到浏览器本地。

④ 常见问题

GPT（OpenAI）模型连不上？需要科学上网。

点了没反应？刷新页面，或检查 API Key 与服务商地址是否填写正确。
